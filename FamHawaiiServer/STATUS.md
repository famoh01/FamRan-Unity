# FamHawaii — สถานะงานทดลอง

- ฝั่งเซิร์ฟเวอร์ในโฟลเดอร์นี้เป็น **ต้นแบบทดสอบบน localhost เท่านั้น** ไม่ใช่เซิร์ฟเวอร์เกมพร้อมใช้งาน ไม่มีข้อมูลถาวร ไม่มี TLS ไม่มีระบบโลกเกม และห้ามเปิดให้ผู้เล่นทั่วไปใช้
- API ต้นแบบส่งชื่อ `FamHawaii` และสถานะ offline เพื่อทดสอบการแสดงชื่อเท่านั้น
- ตัวเกมต้นฉบับยังตั้งที่อยู่ 127.0.0.1 จึงไม่สามารถติดต่อเซิร์ฟเวอร์บนอินเทอร์เน็ตจากโทรศัพท์ได้โดยไม่มีการกำหนดปลายทางจริง
- ตารางข้อความไทยใน `Assets/Resources/_localization/ui_th.json` เติมคีย์ที่ขาดจากตารางอังกฤษแล้ว ส่วนที่เพิ่มใช้การแปลด้วยเครื่องและต้องตรวจทาน; รายการที่อยู่นอกตารางนี้ยังไม่ได้แปลทั้งหมด
- สคริปต์จัดการภาษาและป้ายข้อความได้รับการซ่อม แต่การเชื่อมป้ายทั้งหมด ฟอนต์ไทย และการแสดงผลในแอปยังไม่ได้ทดสอบ
- APK ก่อนหน้านี้ยังมี 14 ข้อผิดพลาด NavMesh และยังไม่ได้พิสูจน์ว่าเล่นได้จริง

ทดสอบต้นแบบ: `cd FamHawaiiServer && python3 -m unittest -v test_protocol test_handshake test_auth_probe`
